# ГостSign

Открытое браузерное приложение для подписания PDF по российскому законодательству:
настоящая **PAdES-подпись** (CMS внутри `/Contents`, покрытие через `/ByteRange`)
сертификатами ГОСТ Р 34.10 через **КриптоПро ЭЦП Browser plug-in**.

Бэкенда нет. Документ и закрытый ключ не покидают компьютер пользовател.

**Статус:** подписанные документы принимаются Госуслугами — проверено на боевом сертификате.

## Что умеет

- Drag&drop PDF, превью страниц (pdf.js).
- Список сертификатов из личного хранилища (`CAPICOM.Store`, фильтр `TIME_VALID`).
- Deferred signing в три фазы: заготовка с плейсхолдером → `SignHash` в плагине → вставка CMS.
- Видимый штамп по **ГОСТ Р 7.0.97-2016 п. 5.23** — векторный appearance stream внутри
  подписанного диапазона; все реквизиты берутся только из сертификата.
- Перетаскивание и изменение размера штампа по превью, автоподбор кегля, контроль
  минимального размера и запрет наложения на существующие подписи.
- Мультиподпись: каждый раз новый incremental update, старые подписи остаются валидными.
- CAdES-BES по умолчанию, CAdES-T (штамп времени) — переключателем.
- Панель диагностики: разбор `/ByteRange` и `/Contents`, структура CMS, пересчёт хэша
  плагином и сверка с `messageDigest`.

## Требования на машине пользователя

- КриптоПро CSP;
- КриптоПро ЭЦП Browser plug-in (отдельная программа) + расширение браузера.

`public/vendor/cadesplugin_api.js` — официальный API-файл плагина. **Версия важна:**
в старых версиях зашиты ID только MV2-расширений, и в современном Chrome загрузка
падает с `chrome-extension://invalid/`. Здесь лежит 2.4.5 (знает MV3-расширение
`pfhgbfnnjiafkhfdkmpiflachepdcjod`). Обновлять — с сайта КриптоПро.

## Разработка

```bash
pnpm install
pnpm dev
```

Оффлайн-проверка ядра (incremental update и мультиподпись, без криптографии):

```bash
pnpm check
```

## Устройство

| Файл | Назначение |
|---|---|
| `src/lib/cades.ts` | всё общение с плагином: сертификаты, `SignHash`, хэш, перевод ошибок в человеческие |
| `src/lib/pdfSign.ts` | ядро: incremental update, словарь подписи, `/ByteRange`, штамп |
| `src/lib/pdfInspect.ts` | диагностика готового файла, сверка `messageDigest` |
| `src/lib/asn1.ts` | минимальный DER-парсер (только разбор CMS для отладки) |

Собственной криптографии в проекте нет и быть не должно: хэш и подпись считает
сертифицированное СКЗИ на машине пользователя.

## Ограничения

- Вьюер PDF без поддержки ГОСТ-подписей (например, Adobe Reader без плагина КриптоПро PDF)
  покажет «статус подписи неизвестен» — это ограничение вьюера, а не дефект подписи.
- `/DocMDP` не ставится намеренно — иначе последующие подписи ломали бы первую.
- Зашифрованные (парольные) PDF не поддерживаются.
